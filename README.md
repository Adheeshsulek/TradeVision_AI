# TradeVision AI

TradeVision AI is an AI-powered stock market analysis platform built using Python, Streamlit, Plotly, OpenCV, Pandas, NumPy, and Yahoo Finance.

## Features

### Market Analysis

* 50+ NSE Stock Selector
* Candlestick Charts
* EMA 20 & EMA 50 Trend Analysis
* Support & Resistance Detection
* Breakout Detection

### Pattern Recognition

* Hammer Detection
* Shooting Star Detection
* Doji Detection
* Bullish Engulfing Detection
* Morning Star Detection
* Evening Star Detection
* Double Top Detection
* Double Bottom Detection
* Head & Shoulders Detection
* Ascending Triangle Detection

### Trade Setup Generator

* Entry Price Calculation
* Stop Loss Generation
* Target 1 & Target 2 Calculation
* Risk Reward Analysis
* Trade Quality Rating

### AI Screenshot Analyzer

* Upload Trading Chart Screenshots
* OpenCV-based Image Processing
* Trend Detection
* Screenshot Analysis Dashboard

## Installation

```bash
git clone https://github.com/Adheeshsulek/TradeVision_AI.git

cd TradeVision_AI

pip install -r requirements.txt

streamlit run app.py
```
